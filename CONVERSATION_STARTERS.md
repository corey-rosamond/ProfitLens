# 💬 ProfitLens Conversation Starters

## 10 Optimized Conversation Starters for GPT Configuration

### 1. Quick Analysis (Most Common Use)
```
Calculate FBA fees for my product
```
*Triggers: Basic fee calculation flow*

### 2. Complete Analysis Example
```
Analyze: yoga mat, $25, 2lbs, BSR 5000, costs me $8
```
*Triggers: Full analysis with all features*

### 3. BSR Lookup
```
What's the sales volume for BSR 10,000 in Home & Kitchen?
```
*Triggers: Sales estimation with velocity check*

### 4. Portfolio Building
```
Help me build an FBA portfolio with $20,000
```
*Triggers: Portfolio management and investment planning*

### 5. Quick Decision
```
Quick check: $30, 3lbs, Toys, BSR 8000
```
*Triggers: Speed mode for experienced users*

### 6. Beginner Help
```
I'm new to Amazon FBA - help me understand the basics
```
*Triggers: Educational mode with gentle introduction*

### 7. Product Comparison
```
Compare these: water bottle vs yoga mat vs resistance bands
```
*Triggers: Multi-product comparison tools*

### 8. Risk Assessment
```
Is this risky? Low margin product with high competition
```
*Triggers: Risk scoring and warning system*

### 9. Launch Planning
```
Create a launch strategy for my new product
```
*Triggers: 8-week launch roadmap generator*

### 10. Profitability Check
```
Will I make money? $20 price, $7 cost, 1lb, Kitchen
```
*Triggers: Break-even analysis and profitability focus*

## 📝 Implementation Notes

### In GPT Builder:
1. Choose 4 starters initially (GPT Builder limit)
2. Rotate them monthly based on usage
3. A/B test different versions

### Recommended Initial 4:
1. "Calculate FBA fees for my product" (covers basics)
2. "Analyze: yoga mat, $25, 2lbs, BSR 5000, costs me $8" (shows format)
3. "Help me build an FBA portfolio with $20,000" (advanced feature)
4. "I'm new to Amazon FBA - help me understand the basics" (beginners)

### Why These Work:
- Cover different user types (beginner to expert)
- Showcase different features
- Natural language that users would actually type
- Range from simple to complex
- Include example format for one
